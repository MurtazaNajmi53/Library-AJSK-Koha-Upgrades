# OPAC v8.2: Gate 0 design audits (before code)

13 Nov 2026, against the live v8.1 OPAC (results for "healing", record 13490, the cart pull-out and the New arrivals popup at 1440px, plus a 390px same-origin frame). I read `design-system/CLAUDE.md`, `README.md`, `components/Menu/README.md` and `components/RecordDetail/README.md` first. Where a skill disagrees with the brand book, the brand book wins. That happened twice:

- **Capitals.** The ux-writing skill wants title case for titles and menus. The brand book uses sentence case everywhere.
- **Metadata strings.** The brand book bans "A · B · C" strings. So a result's author line reads "Yucel Salih, 2008", not "Yucel Salih · 2008".

Severity uses Nielsen's scale: 0 means not a problem, 1 cosmetic, 2 minor, 3 major, 4 catastrophe.

## 1. design-skills:design-critique (heuristics, UX laws, excise)

**Who and what.** The users are students, most of them perpetual intermediates on phones. They come to find a book and collect it, so the screens are transient: brief visits, in and out.

**5-second test**
- **Results:** the eye lands on the copper Click & Collect button. That part works. But each row then offers 3 actions and 7 lines of metadata, so the title isn't what reads first.
- **Record page:** on desktop, Click & Collect is clear. On a phone the page opens on the cover and details, and the action panel comes after the holdings, about 3 screens down.

## 2. design-skills:interaction-design (state machines)

**More options menu**
```
[closed] --click/Enter/Space/ArrowDown--> [open, focus first item]
[open] --Escape--> [closed, focus trigger]
[open] --Tab / click outside--> [closed]
[open] --choose item--> [closed] + item's own action (Koha modal, link)
```
The trigger always shows `aria-expanded`. Results rows have an icon-only trigger, so its name carries context: "More options for <title>".

**Select mode (results).** Select mode is a mode, so it must be impossible to miss.
```
[off] --press "Select titles"--> [on, 0 selected]   (checkboxes + sticky toolbar appear; trigger aria-pressed=true)
[on, 0] --tick--> [on, n]       toolbar shows "n selected"; actions enabled
[on, n] --untick to 0--> [on, 0] actions disabled, toolbar says "Tick titles to act on them"
[on, *] --press "Done" or trigger--> [off]   ticks are cleared, so no hidden selection survives
[on, n] --Click & Collect selected--> Part E orderMany (its own dialog)
```
- Leaving Select mode clears the ticks. A selection you can't see is a trap.
- The toolbar has a visible "Done" button, as well as the pressed trigger.

**Cart toggle (Part H)**
```
[out] --press--> [in]  label flips to "Remove from cart" at once (optimistic), then Koha's addRecord runs
[in] --press--> [out]  label flips back at once, then delSingleRecord runs
Koha refuses (cart full) --> revert label and let Koha's own message show
```
- No spinner. Both calls are local cookie writes that finish in well under 100 ms.

**Click & Collect (Part E)**
```
[slot skeleton] --status known--> [ready: Click & Collect] | [on loan: Reserve] | [ordered: disabled "Ordered"]
[ready] --press--> [dialog open, dates loading (skeleton)] --dates--> [choose date] --Confirm order--> [placing…] --> [ordered]
                                                          --error--> message in the dialog + Try again
```
- Today the button sits in "Checking…" for about 3 s before the dialog opens. v8.2 opens the dialog straight away and loads the dates inside it (G6).

## 3. design-skills:ux-writing (new labels)

| Proposed | Verdict | Final |
|---|---|---|
| More options | Clear, 2 words. On icon-only triggers, add the title | "More options" (`aria-label` "More options for <title>") |
| Select | Too bare: select what? | "Select titles" |
| N selected | Fine | "3 selected" (numerals), and "Tick titles to act on them" at 0 |
| More about this title | Fine, user-centred | "More about this title" |
| Library views | Jargon, and it doesn't say who it's for | "Librarian views" (MARC view, ISBD view) |
| Save record as | "Save" clashes with "Save to your lists" | "Download record as" |
| Back to normal view | "Normal view" is Koha's jargon | "Back to the record" |
| On the shelf / On loan | Matches the cart and the popup | Keep |
| Where to find it | Plain, answers the student's question | Keep, as the holdings column header |
| Account settings | Fine | Keep |
| Nothing borrowed or due | Reads oddly | "You have nothing borrowed" |
| Done (new, Select mode) | Fine | "Done" |
| Create a list (Lists empty state) | Fine | "Create a list" |

All labels are sentence case. None has an exclamation mark, a "Submit" or an arrow after it.

## Changes to the plan from Gate 0
1. D1 is severity 3 and must ship.
2. Select mode gets the trigger label "Select titles", a "Done" button in the toolbar, and ticks cleared on exit.
3. The new labels are the ones in the "Final" column above.
4. Click & Collect opens its dialog at once, with a skeleton (G6).
