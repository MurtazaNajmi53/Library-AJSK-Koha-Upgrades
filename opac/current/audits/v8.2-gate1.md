# OPAC v8.2: Gate 1 audits (after implementation)

These were run on 13 Nov 2026 against the v8.2 masters, swapped into the live catalogue with `tests/opac-harness/live-swap.js`. The site-wide checklist re-audit (frontend-design, Vercel web-design-guidelines, ui-ux-pro-max) is recorded finding by finding in `v8.2-site-audit.md`.

## design-skills:accessibility-audit (WCAG 2.2 AA)

| Check | Result |
|---|---|
| More options menu: trigger `aria-expanded`; ArrowDown opens and focuses the first item; arrows, Home and End move; Escape closes and returns focus | Pass. Checked by keyboard on the results row and on the record panel |
| Results row ⋯: accessible name | Pass. "More options for <title>" |
| Select titles: `aria-pressed`; count in `role=status` | Pass. Reads "Tick titles to act on them", then "1 selected" |
| Select mode: ticks cleared on Done; Escape leaves the mode | Pass |
| Click & Collect dialog: native modal `<dialog>` (focus trapped); focus on the chosen date; Escape closes; focus returns to the Click & Collect button | Pass |
| Date cards: native radios, so arrow keys move between them; `:focus-visible` ring on the card; chosen card shown by a tick as well as colour | Pass |
| Cart ticks in the dialog: native checkboxes, label and control on one target | Pass by construction. Not exercised, as it needs a multi-title order |
| Loading: dialog `aria-busy` plus a screen-reader "Checking…" status | Pass |
| Holdings: drawn as CSS grids, so explicit `role` table, rowgroup, row, columnheader and cell were added | **Fixed in Gate 1** |
| "More about this title": native `<details>` | Pass |
| Contrast of new pairs | Pass: status pill copper-800 on sand, about 6:1; muted labels on white, about 6:1; white on action, about 4.9:1 |
| Targets | Pass: every new control is 44px or larger (dialog buttons 48px, date cards 60px) |
| Reduced motion | Pass: section 20m; dialog and menus fade only |

## hzblj-skills:ui-interactions

| Check | Result |
|---|---|
| Press scale | Buttons scale to 0.96. Close buttons were at 0.94, below the 0.95 floor: **fixed to 0.96**. The full-width date cards stay at 0.98 on purpose, as a 4% press there jumps 20px |
| Hover only under `(hover: hover)` | Pass |
| Disabled controls don't press | Pass (`:not(:disabled):active`) |
| Loading button keeps its width | Pass (Confirm order keeps `min-width` while placing) |
| No `transition: all` | Pass |

## design:design-critique (second opinion against the brief)

Each screen now leads with one action: Click & Collect, or Click & Collect all in the cart. Everything else is one press away.

| Finding | Sev | Action |
|---|---|---|
| Phone record page: the breadcrumb wrapped to two lines above the cover | Minor | **Fixed**: hidden on phones |
| Record "More options" lists 8 download formats | Minor | Accepted: hidden by default and grouped under its own heading |
| "Select titles" sits at the end of the sideways bar on phones | Minor | Accepted: selecting several titles is a rare task |
| Home with no notices: the My library card is wide and sparse | Minor | Accepted for now |
