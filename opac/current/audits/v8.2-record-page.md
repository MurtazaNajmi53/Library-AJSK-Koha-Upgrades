## Layout

```
Home › The kite runner
┌────────┐  The kite runner                      (display title, full width)
│ cover  │  by Hosseini, Khaled
│180×270 │  ┌──────────────────────────────────────────────────────────────┐
│        │  │ ◷ On loan                     [Reserve] [Add to cart] [⋯ More]│
│        │  │ Mezzanine Floor Stack, call number 823.92                    │
└────────┘  └──────────────────────────────────────────────────────────────┘
            Published London : Bloomsbury, 2014
            Subjects Teenage boys -- Afghanistan | …
            More about this title ˅            (facts in columns when open)
Holdings (1) | Title notes (3)
[ Status | Where to find it | Call number | Collection | Item type ]  full width
```

The strip is the page's one emphasis: a sand band (`surface-band`, `radius-lg`) that joins "is it here, where" to "get it". Everything else stays quiet. Colours, type and shapes are the design system's own; nothing new was introduced.
