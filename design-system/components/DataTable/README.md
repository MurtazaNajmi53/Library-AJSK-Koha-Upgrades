A table for structured data: holdings, rubrics, opening hours. Provide a caption, column headers with `scope="col"`, and row headers with `scope="row"`.

## Behaviour
Sticky head, band fill on row hover, scrolls sideways inside its wrapper on small screens. Numeric columns (`.aj-num` or `data-num`) align to the end with tabular figures.

## Tokens
`surface-card`, `surface-band`, `text`, `text-muted`, `border-subtle`, `border-strong`, `radius-md`, `space-3`, `space-4`.
