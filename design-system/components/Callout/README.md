A single point the reader should keep, beside the main text. The title says the point; no label above it.

## Passage
`.aj-passage` holds a Quranic, hadith or LSD passage on its own line: right to left, `rtl-passage` size, dashed `ornament` border. Set `lang="ar"`.

## Tokens
`surface-card`, `border-strong`, `text-heading`, `text-muted`, `ornament`, `radius-md`.
