The member's summary: a large count for the term and one linked row per status.

## States
`is-good` (number in `text-heading`), `is-soon` (number in `action`), `is-alert` (whole row bold in `text-accent`), `is-zero` (row muted, number regular). Each state is also in the words, so colour is never the only cue.

## Behaviour
Each row is a 44px link with a band fill on hover. The count uses tabular figures.

## Tokens
`text-heading`, `action`, `text-accent`, `text-muted`, `surface-band`, `border-subtle`, `size-target`.
