Page links for result lists. Provide a `nav` with `aria-label`, the current page marked `aria-current="page"`, and previous/next with hidden text labels.

## States
Rest: link colour, no border. Hover: band fill. Pressed: 0.96. Current: `action-secondary` fill. Disabled: `aria-disabled="true"` at `opacity-disabled`.

## Tokens
`text-link`, `surface-band`, `border-strong`, `action-secondary`, `on-action-secondary`, `size-target`, `radius-pill`, `space-1`, `space-3`.
