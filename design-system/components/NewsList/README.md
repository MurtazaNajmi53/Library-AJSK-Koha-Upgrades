A list of library news inside a Panel. Provide title, body (may contain lists, tables or images from Koha news) and date.

## Behaviour
Long lists scroll inside the panel. Titles underline on hover. Images in the body get `radius-sm`.

## Loading
While news loads, show Skeleton lines and set `aria-busy="true"` on the panel.

## Tokens
`text`, `text-link`, `text-muted`, `border-subtle`, `space-4`.
