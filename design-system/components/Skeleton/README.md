Grey shapes where content will appear, so the layout does not jump. Match the shape and size of the real content.

## Behaviour
A slow opacity pulse (1.4s). Static under reduced motion. Replace in place when content arrives; no fade needed.

## Accessibility
Put `aria-busy="true"` and a label on the container; remove both when loaded.

## Tokens
`surface-band`, `radius-sm`, `opacity-skeleton`.
