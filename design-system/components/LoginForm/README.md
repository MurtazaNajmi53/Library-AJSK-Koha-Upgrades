The OPAC login page: a card with large fields on one side and help items on the other; stacked under 992px.

## Behaviour
Submit shows the loading state until the page changes. "Show password" toggles the field type. Fields are 52px.

## Note
The copper inline-start bar on help items comes from your stylesheet. It is the one place the system uses an accent bar; keep it there only.

## Tokens
`surface-card`, `border-subtle`, `shadow-card`, `ornament`, `radius-lg`, `radius-md`, `size-control-lg`, `space-5`, `space-8`, `space-12`.
