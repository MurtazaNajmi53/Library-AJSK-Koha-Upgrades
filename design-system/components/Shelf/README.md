A horizontal row of covers for new arrivals. Provide a list of cover links with title and author; add `data-aj-shelf`.

## Behaviour
Scroll snaps to covers. Arrow buttons page by 85% of the visible width with smooth scrolling (instant under reduced motion), hide at either end, and are hidden on touch screens where swiping does the job. Covers lift on hover. RTL scrolls the other way and the arrows flip.

## Accessibility
The track is focusable (`tabindex="0"`) so keyboard users can scroll it with arrow keys; arrow buttons have labels.

## Tokens
`ornament` (scrollbar), `text`, `text-muted`, `space-4`, `size-target`, `size-cover-w`.
