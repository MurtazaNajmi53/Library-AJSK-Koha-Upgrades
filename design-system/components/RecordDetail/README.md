The record page: a 200px cover beside the title, details, view pills and the action bar. On phones the cover stacks above.

## Anatomy
Cover (`--lg`), `h1` title, subtitle/author, details `dl`, view pills (`aria-current="page"` on the current view), action bar (`radius-lg`, the largest container).

## Tokens
`text-heading`, `text-muted`, `surface-card`, `border-subtle`, `surface-band`, `radius-lg`, `space-5`, `space-10`.
