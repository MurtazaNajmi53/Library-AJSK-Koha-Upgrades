- `aljamea-logo.svg` (750 x 320): the Aljamea-tus-Saifiyah wordmark in Arabic calligraphy with the Latin line "Aljamea-tus-Saifiyah" below it, as supplied, single ink #1C388C (`logo-blue`). On screen, do not place this file with `<img>`: use `.aj-logo`, which draws the same artwork in the `logo` token so it follows the theme (heading blue in light, periwinkle in dark). Use the file as supplied for print, email and partners. Keep clear space of at least the height of the Latin line, a minimum height of 40px, and never stretch it or add effects.
- `aljamea-logo-cream.svg`: the same artwork in cream (#FEF9F1) for places that cannot use CSS, such as slides on `surface-inverse` and email signatures.
- `rosette-motif.png` (800 x 800): four-petal rosette in a ring, gold (`brand-gold`, #D5B36F) on transparent. Use large and faint behind slide covers and section openers, and as the loader mark. Gold on cream is faint by design; do not use it for anything that must be read.
- `rosette-mark.png` (400 x 816): the small rosette with a thin vertical rule below it, same gold. Use as a title-slide mark or an opening divider on dark grounds.
- `wordmark-cream.png` (694 x 332): the Arabic library wordmark (مكتبة, with the line "الجامعة السيفية") in cream, #FEF9F1, on transparent. Use only on `surface-inverse` or dark-theme grounds. There is no navy version in the sources; the website's navy logo is loaded by the OPAC from the Aljamea website.
