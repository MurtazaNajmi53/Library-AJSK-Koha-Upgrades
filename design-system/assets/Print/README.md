`JDC_Cover.pdf` is the cover of the Decimal Classification System booklet and the reference for printed covers: `cream` ground, a `copper` double frame, the Aljamea-tus-Saifiyah wordmark in `blue` at the top, a copper rosette disc above a short vertical rule, the Arabic title in Amiri Bold, a short copper rule, the English title (the original uses DM Serif Display), and a `sand` footer band with the Arabic library name and an italic line. Keep that order for new covers, but set the English in DM Sans (`cover-title`, weight 750, tight tracking) and the footer line in DM Sans; the system no longer uses a Latin serif.
